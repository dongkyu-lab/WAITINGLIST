# 인사·사용량

## 모델 배치 원칙
- **opus** (비쌈·최고 품질): 본부장(effort 중간), SNS기획담당, 세무책임 — 창의 기획과 세법 판단만.
- **sonnet** (중간): 팀 책임자·작성 담당 — 문서 작성, 검수, 고객 대응.
- **haiku** (가장 쌈·빠름): 정리·분류·대량 반복 — 발행자료, 체험단 운영, 데이터 집계, 리뷰 일반 답글, 장부 분류, 교정.

## 조정 기준 (본부장이 매주 점검)
- haiku 결과를 sonnet이 계속 고치고 있으면 → 해당 직원 sonnet으로 승급.
- sonnet 결과가 수정 없이 계속 통과하면 → effort 낮추기 검토.
- opus 직원이 단순 작업에 불리면 → 그 일은 아래 직원에게 재배정.
- 모델 변경은 `.claude/agents/<이름>.md`의 `model:` / `effort:` 한 줄만 바꾸면 된다.
