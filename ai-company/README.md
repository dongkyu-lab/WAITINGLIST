# AI회사 (대표 → 본부장 → 8개 팀)

대표님은 **본부장하고만** 대화합니다. 본부장(Opus · effort 중간)이 일을 팀 직원(서브에이전트)에게 나눠 주고, 검토한 뒤 결재를 올립니다.

## 시작
```bash
cd ai-company
claude
```
이 폴더에서 실행하면 `CLAUDE.md`(본부장 규칙), `.claude/settings.json`(Opus·중간), `.claude/agents/`(직원 16명)가 자동 적용됩니다.

예) "다음 달 체험단 10명 모집 기획해줘", "10월 카드내역 정리해서 부가세 집계 만들어줘" (파일은 `자료/`에 넣기)

## 상황실 (대시보드)
본부장이 쓰는 파일(`상황실/`)과 Claude Code 사용 기록을 읽어 보여 주는 화면입니다. Node.js 18 이상만 있으면 되고, 따로 설치할 것은 없습니다.

```bash
npm start          # 실제 상황실 → 브라우저가 http://localhost:4747 로 열림
npm run demo       # 샘플 데이터로 미리 보기 (실제 폴더는 안 바뀜)
```
Windows에서는 `상황실열기.cmd`를 더블클릭해도 됩니다.

| 탭 | 내용 |
|---|---|
| 브리핑 | 대표님 할 일(결재·요청·2주 내 일정) + 본부장 일별 브리핑 |
| 결재함 | 승인 / 수정지시 / 반려 + 메모. 결과 파일을 눌러 미리보기 |
| 완료 보관함 | 프로젝트별 결재① 기획안 → 결재② 완성본 진행과 기록 |
| 조직도 · 직원소개 | `.claude/agents/`를 읽어 자동 생성. 작업 중인 직원은 초록 불 |
| 인사·사용량 | 직원별·모델별 토큰, opus 비중, 캐시 재사용률, 모델 배치 조정 제안 |
| 캘린더 | `상황실/캘린더.md` 일정과 결재 상신일 |

결재 버튼을 누르면 문서가 `완료보관함/`으로 옮겨지고 `본부장 처리: 미반영`이 붙습니다. 다음에 본부장과 대화하면 본부장이 이걸 보고 이어서 일합니다.
서버는 이 컴퓨터(localhost)에서만 열리고, 회사 폴더 밖의 파일은 읽지 않습니다.

## 모델 배치 (토큰 최적화)
- **opus**: 본부장, SNS기획담당, 세무책임 — 창의 기획·세법 판단만
- **sonnet**: 팀 책임자·작성 담당 (세금계산서팀장, 체험단기획, 보고서책임, 견적서, SNS제작, 리뷰관리책임, 인사, 조사)
- **haiku**: 반복·정리 (발행자료, 체험단운영, 보고서데이터, 리뷰답글, 장부정리, 교정검수)

모델을 바꾸려면 `.claude/agents/<이름>.md`의 `model:` / `effort:` 줄만 수정하세요.
